## ⛧ ¿QUÉ ES EL ARCHIVO?

**El Archivo Olvidado** es una experiencia web de horror interactivo desarrollada con **Angular 21**, **Three.js** y APIs nativas del navegador.

No pretende ser simplemente una wiki de creepypastas.

Es un **archivo digital contaminado**.

Dentro encontrarás expedientes de entidades y personajes, leyendas latinoamericanas, sucesos liminales, rituales interactivos, anomalías audiovisuales y una casa abandonada explorable en primera persona.

## 🪞 PROTOCOLO DEL ESPEJO

Al seleccionar **Activar cámara frontal**, el navegador solicita permiso para utilizar la cámara.

La cámara es completamente opcional.

Si el usuario rechaza el permiso, el ritual continúa utilizando una simulación.

> [!IMPORTANT]
> El vídeo se procesa localmente.  
> **No se graba. No se almacena. No se sube. No utiliza el micrófono.**

Durante el ritual, el reflejo comienza a oscurecerse.

Mantén pulsado el cristal durante:

```text
00:00:10
```

o mantén presionada la tecla:

```text
SPACE
```

con el espejo enfocado.

Después...

**Bloody Mary aparece.**

### Protocolo de cierre de cámara

La cámara se apaga automáticamente al:

- cambiar de ritual;
- abandonar la sección;
- ocultar la pestaña;
- pulsar **Apagar cámara**.

Las solicitudes de cámara que todavía estén pendientes son invalidadas al abandonar la escena.

La API requiere:

```text
HTTPS
```

o:

```text
localhost
```

Por ese motivo una dirección HTTP dentro de una red local puede no permitir probar la cámara desde un teléfono.

GitHub Pages utiliza HTTPS.

> El progreso de un ritual se registra **cuando se ejecuta**, no simplemente cuando se selecciona.

# 🏚 LA CASA DEL AZOGUE

```text
LOCALIZACIÓN ........ DESCONOCIDA
ESTADO .............. ABANDONADA
ELECTRICIDAD ........ INESTABLE
SALIDAS ............. 01
PRESENCIAS .......... MÚLTIPLES

OBJETIVO:

[ ] ENCONTRAR LA LLAVE
[ ] RECUPERAR PRUEBA 01
[ ] RECUPERAR PRUEBA 02
[ ] LLEGAR A LA SALIDA
[ ] SOBREVIVIR
```

**La Casa del Azogue** es una experiencia 3D de horror en primera persona integrada directamente en el Archivo.

La historia comienza con un prólogo dividido en **cuatro fragmentos**, que puede recorrerse completamente o saltarse.

Después...

la puerta se abre.

La casa contiene habitaciones y pasillos conectados, madera deteriorada, humedad, mobiliario abandonado, sangre, iluminación cálida, niebla y distintas presencias.

Tu objetivo es recuperar:

```text
1 × LLAVE
2 × PRUEBAS
```

y alcanzar la salida.

# ⚙ RENDIMIENTO

```text
[ DIAGNÓSTICO DEL MOTOR ]
```

Three.js se carga de forma **diferida** cuando el usuario inicia la historia.

Las paredes utilizan renderizado mediante instancias.

Las rutas internas se reutilizan.

La resolución está limitada inicialmente a:

```text
1.5×
```

y puede reducirse automáticamente a:

```text
1×
```

si el sistema detecta fotogramas lentos.

Cuando el juego entra en pausa:

```text
RENDER LOOP ........ DETENIDO
```

Cuando el sistema solicita reducción de movimiento:

```text
ANIMACIONES ......... REDUCIDAS
```

### Requisitos gráficos

El navegador necesita:

```text
WebGL
+
ACELERACIÓN GRÁFICA
```
